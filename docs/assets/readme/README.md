# README figures

For the real-data walkthrough and its evaluation boundary, see the
[platelet case demo](../../../examples/platelet/README.md).
The current homepage uses its [five-model gallery](../../../examples/platelet/multimodel_umap.png),
generated by the notebook's `platelet-figure` cell. The single-model image below
is retained with its original provenance.

`workflow.svg` describes the current portable evaluation in
[`evaluate_embeddings`](../../../src/scfm_benchmark/benchmark.py): identity
alignment, dependency-group folds shared across representations, fold-fitted
scaling / optional PCA / logistic regression, and donor-mean held-out predictions.
It is a schematic, not a measured result. The training-prior baseline is fitted
on the same training cells.

`historical_umap.png` redraws the stored scPRINT-2 coordinates in
[`umap_scprint2.csv`](../../../scripts/24_option_c_canonical_input/results/option_c_bio_interpretation/umap_scprint2.csv).
The historical [producer](../../../scripts/24_option_c_canonical_input/code/biological_interpretation_option_c.py)
and [summary](../../../scripts/24_option_c_canonical_input/results/option_c_bio_interpretation/summary_scprint2.json)
are retained in the repository. The plotted table contains 43,803 unique cell
IDs. Both panels use every row, the same coordinates, identical axis scales and
the same shuffled drawing order (seed 42); only the coloring changes.
The cohort codes and severity strings are used as stored, without relabeling.

This is a historical input snapshot from before the QC rebuild, not an output
of `scfm-bench demo`, an updated biological result, or evidence of model
superiority. The original coordinate-producing run was not rerun or independently
reconstructed for this display. No UMAP, embedding model, classifier or QC rule
was fitted by the figure script. A 2D projection cannot establish biological
validity, quantify confounding or demonstrate its removal.

## Reproduce the display

From the repository root, with NumPy, pandas and Matplotlib installed:

```bash
python docs/assets/readme/plot_figures.py --out new-readme-figures
```

For this project, run on HPCC under the existing execution rules. The output
directory must be new; the input coordinate file is never modified. The command
writes the workflow in SVG and PNG, the UMAP in PNG, and a provenance manifest.
Only the SVG workflow and PNG UMAP are needed by the README; the workflow PNG
is a visual-check output. [provenance.json](provenance.json) records the source
and renderer hashes, label counts, drawing settings, versions and output hashes.

The synthetic benchmark result graphic remains in
[`examples/benchmark/preview.svg`](../../../examples/benchmark/preview.svg),
with its executed-run evidence in that directory.
