Evaluation contract

  • Cells align by cell ID. Donors have one label and one dependency group.
  • Splits use donor rows and keep entire dependency groups together; every representation uses identical folds.
  • Scaling, optional PCA and logistic regression fit training cells only. Training weights each cell equally.
  • Held-out cell probabilities are averaged within donor; metrics weight each donor equally.
  • This probes fixed input representations. It cannot rule out leakage during upstream pretraining, fine-tuning or feature selection.
